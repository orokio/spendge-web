# spendge-web

海绵记账的公开站点，只包含静态页面，不含客户端源码。

- `index.html` 首页
- `support.html` 使用帮助（App Store 技术支持网址）
- `privacy.html` 隐私政策

## 发布

GitHub → 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/`（root），保存后等一两分钟。

地址：

- 支持：https://orokio.github.io/spendge-web/support.html
- 隐私：https://orokio.github.io/spendge-web/privacy.html

域名备案通过后，把页面迁到 `https://www.orokio.com`，再在 App Store Connect 更新链接即可。
